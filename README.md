# EntryPro

Система автоматизированного учета рабочего времени сотрудников с верификацией местоположения через REST API и HTTP Геокодер Яндекс Карт.

Проект представляет собой монолитное веб-приложение на базе фреймворка Flask, разделяющее права доступа для администраторов и линейного персонала.

## Основной функционал

* **Система аутентификации:** Разделение ролей на `Администратор` (Admin) и `Сотрудник` (Employee). Хэширование паролей пользователей по стандарту SHA-256.
* **Личный кабинет сотрудника:** Автономное управление рабочими сменами (открытие/закрытие) в один клик.
* **Верификация локации:** Интеграция с HTML5 Geolocation API на фронтенде и HTTP Геокодером Яндекс Карт на бэкенде. При открытии смены фиксируются GPS-координаты устройства, которые сервер преобразует в реальный адрес для защиты от ложных отметок.
* **Панель администратора:** Сквозной онлайн-мониторинг текущего статуса всех сотрудников компании, истории их смен, расчет точной длительности работы и логирование физических адресов точек входа.

## Архитектура и технологии

* **Backend:** Python 3, Flask (управление сессиями, маршрутизация, REST API)
* **Database:** SQLite3 (реляционная база данных для хранения учетных записей и логов сессий)
* **Frontend:** Чистый HTML5 / CSS3 (адаптивная монохромная верстка без сторонних тяжелых фреймворков)
* **API Интеграция:** Яндекс Карты (HTTP Геокодер) через библиотеку `requests`

```text

├── database.db          # Локальная БД SQLite (создается автоматически)

```
