# 🛡️ EntryPro

> **Автоматизированная система учета рабочего времени сотрудников с интеграцией Telegram Bot API**

EntryPro — это легковесное и надежное десктопное приложение, созданное для прозрачного контроля рабочих смен в малом и среднем бизнесе. Система решает проблему «человеческого фактора» при заполнении табелей, предоставляя руководству live-мониторинг активности, а сотрудникам — удобный таймер и мгновенные уведомления в мессенджер.

---

## 💻 Ключевой функционал

### Кабинет сотрудника
* **Управление сменой в 1 клик:** Быстрый старт и завершение рабочего дня через интуитивную кнопку-переключатель.
* **Live-таймер:** Секундный счетчик времени, показывающий точную длительность текущей сессии.
* **История:** Отображение таблицы с результатами 5 последних рабочих сессий.
* **UX-интеграция:** Встроенное модальное окно с пошаговым туториалом по привязке Telegram Chat ID, исключающее путаницу при настройке.

### Панель директора
* **Живой мониторинг:** Интерактивная таблица, отображающая статус всех сотрудников («В сети» / «Оффлайн») и точное время их работы в реальном времени.
* **Управление кадрами:** Быстрое добавление персонала с автоматической генерацией криптостойких 8-значных паролей.
* **Безопасное увольнение:** Возможность мгновенной деактивации аккаунтов без удаления их исторического следа в базе данных.
* **Аналитика и экспорт:** Выгрузка всей истории смен и доступов сотрудников в формат `.csv` для последующего анализа в Excel.

---

## 🤖 Интеграция с Telegram Bot API

В приложение встроена система мгновенных уведомлений, работающая напрямую через HTTP-запросы (без тяжелых внешних библиотек):
* **🟢 При начале смены:** Бот отправляет сотруднику сообщение с точным временем старта.
* **🔴 При завершении смены:** Бот присылает финальный отчет с автоматическим расчетом отработанного времени (в формате `ЧЧ:ММ:СС`).

## 🛠 Технологический стек

Проект построен на базе чистого Python и современных библиотек, что гарантирует высокую скорость работы и переносимость:

| Технология | Назначение в проекте |
| :--- | :--- |
| **Python 3.x** | Основной язык бизнес-логики приложения |
| **PyQt6** | Графический интерфейс (UI/UX) в строгом корпоративном Dark-стиле |
| **SQLite3** | Легковесная реляционная БД для локального хранения данных |
| **Secrets / String** | Безопасная генерация паролей для новых учетных записей |
| **Urllib / JSON** | Прямое взаимодействие с Telegram Bot API |
